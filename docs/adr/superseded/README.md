# Superseded decisions

Architecture decisions that no longer apply, kept as the record of why things were
once done that way. Each one names, under its title, the decision that replaced it.
They keep their numbers, so `docs/adr/superseded/0009` is still ADR 0009, and no
number is reused.

Most are the Operator Console's and Bootstrap Launcher's (`docs/adr/0051`,
`docs/adr/0062`). Console-era decisions whose principle still holds stay in
`docs/adr/` with a note saying what carries them today.

A decision moves here when its status becomes `superseded`.
